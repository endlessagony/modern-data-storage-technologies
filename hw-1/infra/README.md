# Инфраструктура для ДЗ 1

Это самостоятельная папка локального стенда. Подробная установка: [macOS](../setup_macos.md), [Windows / WSL](../setup_windows.md). Условие и критерии: [домашнее задание](../homework_01.md). Учебные поля и ограничения: [DATASET](DATASET.md).

## Роли

| Компонент | Назначение |
|---|---|
| MinIO | S3-совместимое хранилище объектов: исходники, файлы таблицы и метаданные |
| Spark | Читает, проверяет и записывает данные |
| Parquet | Колоночный формат файлов, не отдельный сервер |
| Iceberg | Формат таблицы и метаданных, подключённая библиотека |
| PostgreSQL | JDBC-каталог: помогает Spark и Trino найти одну таблицу |
| Trino | Сервер SQL-запросов; CLI включён в контейнер |
| DataGrip | Необязательный SQL-клиент на вашем компьютере |

## Порядок после установки Docker и Python 3

Выполняйте по одной команде; после ошибки остановитесь и прочитайте её, не переходите к следующему шагу.

```bash
docker compose config --quiet
docker compose build
docker compose up -d
docker compose ps --all
docker compose exec -T trino trino --execute "SELECT 1"
python3 generate_dataset.py --rows 200000 --out data/events_demo.csv
docker compose exec -T spark spark-submit /scripts/01_upload_csv.py /data/events_demo.csv
docker compose exec -T spark spark-submit /scripts/02_csv_to_parquet.py
docker compose exec -T spark spark-submit /scripts/03_iceberg.py
docker compose exec -T trino trino < trino/scripts/seminar_demo.sql
```

`minio-init` должен завершиться с кодом 0 — он создаёт бакеты `raw` и `datalake`. Если Trino ещё запускается, посмотрите `docker compose logs --tail=60 trino` и повторите `SELECT 1` после готовности.

Ожидаемые результаты учебного набора: 200000 уникальных событий; первая порция Iceberg — 66553 строки, добавленная — 133447; сентябрьских `purchase` — 4000, среднее — `150808.033185`. Размер и время зависят от запуска. Если результаты не совпали, проверьте seed, число строк и последовательность шагов.

## Файлы и повторный запуск

`scripts/` на компьютере видна контейнеру Spark как `/scripts/`, `data/` — как `/data/`. Генератор создаёт `data/` автоматически. Для собственного решения создайте отдельные пути и схему, например `lakehouse.student_01.weather`. Не используйте имена учебного примера для итоговых данных.

Шаги 01–03 перезаписывают только учебные пути `events`: raw-объект, Parquet и содержимое `lakehouse.dwh.events`. Скрипт 03 затем добавляет непересекающуюся вторую порцию. Не повторяйте его отдельный INSERT вручную: это может добавить дубли. В истории после повторных прогонов может быть больше двух снимков.

Обычная остановка сохраняет данные:

```bash
docker compose down
```

Не добавляйте `-v`, если данные нужны: эта опция безвозвратно удаляет volumes текущего проекта. Не выполняйте команды очистки из чужого каталога. Сервис `memory` Trino не является постоянным хранилищем: справочник восстанавливается SQL-файлом после перезапуска.

## Ограничения

Стенд учебный, не конфигурация для промышленной эксплуатации. PostgreSQL и MinIO используют локальные учебные пароли; Trino не требует пароля. Внешние секреты сюда не добавляйте. Dockerfile фиксирует основные версии Spark, Iceberg и Trino; базовые образы, системные пакеты и некоторые вспомогательные зависимости могут обновляться при новой сборке.

При ошибке отправьте преподавателю ОС, ресурсы ноутбука, точную команду, её вывод и `docker compose ps --all`. Не прикладывайте персональные данные или токены.
