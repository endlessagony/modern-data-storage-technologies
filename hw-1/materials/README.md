# Лекция и семинар 1: комплект для самостоятельной работы

Этот комплект не требует рабочего репозитория преподавателя. Работа по ДЗ **индивидуальная**. На семинаре команды показывает преподаватель; свой стенд запускайте после занятия.

## Начните здесь

1. Прочитайте [условие домашнего задания](homework_01.md): источник и исследовательский вопрос обязательны.
2. Установите и проверьте среду по инструкции [macOS](setup_macos.md) или [Windows / WSL](setup_windows.md).
3. Выполните небольшой синтетический пример из этапа 0 ДЗ: генерация → загрузка → Parquet → Iceberg → SQL.
4. Перенесите подход на собственный открытый источник. Синтетический пример не подходит для итоговой сдачи.
5. Сдайте свой код, SQL, описание и результаты проверок по структуре из ДЗ. Оценка — до 10 баллов; срок смотрите в LMS.

## Состав

```text
lecture_01_student/

  setup_macos.md + setup_macos.pdf
  setup_windows.md + setup_windows.pdf

  infra/
    README.md + README.pdf

    docker-compose.yml
    generate_dataset.py
    spark/           # образ и настройки Spark
    trino/           # образ, каталоги и SQL
    scripts/         # три учебных шага
```

Markdown — редактируемый текст; PDF — копия для чтения. Не нужно отдельно скачивать оба формата, чтобы выполнить команды. Генератор сам создаст `infra/data/events_demo.csv`. В архиве нет больших данных, Docker volumes, локальных паролей внешних сервисов, преподавательских логов и конспектов.

## Где выполнять команды

Все команды `docker compose` и генератор запускайте **из `infra/`**. На Windows используйте Ubuntu/WSL, не PowerShell, кроме явно помеченных шагов установки. Путь вида `/путь/к/...` в документации — пример, замените его на свой.

SQL можно выполнять в [DataGrip](setup_datagrip.md) или в бесплатном CLI внутри контейнера Trino. Выбор клиента не влияет на оценку.

Учебные учётные данные из Compose предназначены только для локальных сервисов. Порты привязаны к `127.0.0.1`: не выставляйте стенд в интернет. Имя Compose-проекта — `hse-lakehouse-student`; не запускайте одновременно две его копии с одинаковыми портами.
