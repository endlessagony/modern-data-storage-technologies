# DataGrip: подключение к Trino для семинара 1

DataGrip используем для SQL и просмотра таблиц, MinIO — для объектов,
терминал — для запуска Spark. Подключение на своём компьютере настройте вручную.

В DataGrip выберите профиль драйвера Trino. Настройки ниже соответствуют
локальному стенду. В этой редакции проверяется SQL через CLI; Test Connection
и SELECT в вашем DataGrip нужно выполнить отдельно.

## 1. Запустите стенд

Автозапуск контейнеров отключён. Если стенд остановлен, откройте Docker Desktop,
дождитесь готовности движка и выполните в терминале:

```bash
cd "/путь/к/lecture_01_student/infra"
docker compose up -d
docker compose ps --all
```

У MinIO и PostgreSQL должен быть статус `healthy`, у Spark и Trino — `Up`.
Готовность Trino дополнительно проверьте запросом `SELECT 1`: отдельного
healthcheck для него в Compose нет.
Завершённый `minio-init` со статусом `Exited (0)` — нормальное состояние.

## 2. Создайте источник данных

1. Откройте DataGrip. В панели Database Explorer нажмите `+` → `Data Source` → `Trino`.
2. Назовите подключение `Семинар 1 — Trino`.
3. Заполните параметры ниже. Если каталог и схема не представлены отдельными
   полями, задайте их через полный JDBC URL.
4. Если появляется ссылка `Download missing driver files`, загрузите JDBC-драйвер.
   Для первого скачивания нужен интернет. Класс драйвера: `io.trino.jdbc.TrinoDriver`.

| Параметр | Значение |
|---|---|
| Host | `localhost` |
| Port | `8088` — опубликованный порт на компьютере |
| User | `teacher` |
| Password | Оставить пустым |
| Catalog | `lakehouse` |
| Schema | `dwh` |
| SSL / SSH tunnel | Не включать: этот локальный стенд использует HTTP |

Полный адрес подключения:

```text
jdbc:trino://localhost:8088/lakehouse/dwh
```

`teacher` — имя пользователя запроса; отдельную учётную запись создавать не нужно.
Пароль MinIO сюда не вводится. Если DataGrip предлагает способ аутентификации,
выберите вариант, позволяющий передать User без пароля; названия зависят от версии.

Нажмите `Test Connection`. При успешной проверке сохраните настройки через
`Apply` / `OK`. Во вкладке `Schemas` отметьте `lakehouse.dwh` и
`memory.default`, если они не появились в дереве автоматически, и обновите дерево.

## 3. Откройте SQL-консоль и проверьте данные

В контекстном меню подключения выберите `New` → `Query Console`.
Выполняйте запросы по одному кнопкой запуска. Для стандартной раскладки macOS
обычно используется `Command+Enter`; сочетание также указано в меню выполнения.

```sql
SELECT 1;
SHOW CATALOGS;
SHOW TABLES IN lakehouse.dwh;
SELECT count(*) AS all_events FROM lakehouse.dwh.events;
SELECT * FROM lakehouse.dwh.events LIMIT 10;
```

После подготовленного прогона в таблице ожидается **200000 строк**.
`SELECT 1` проверяет подключение к Trino; запрос к `events` дополнительно
проверяет доступ к каталогу и файлам в MinIO. Результаты появятся в табличной сетке.

Контрольный аналитический запрос:

```sql
SELECT count(*) AS purchase_events,
       avg(CAST(price_rub AS decimal(18,6))) AS mean_price
FROM lakehouse.dwh.events
WHERE event_type = 'purchase'
  AND event_date >= DATE '2026-09-01'
  AND event_date < DATE '2026-10-01';
```

Для подготовленного набора: **4000** событий и **150808.033185**.
Явный DECIMAL с шестью знаками позволяет сравнить среднее со Spark.
Обычный `avg(price_rub)` в Trino возвращает `150808.03`.

## 4. Подготовьте окно для показа

Откройте `infra/trino/scripts/seminar_demo.sql` в DataGrip и назначьте файлу
подключение `Семинар 1 — Trino` через селектор источника данных редактора.
Запускайте выделенные блоки по очереди: каталоги, таблица, аналитический запрос,
snapshots, создание справочника, затем JOIN. В блоке 3 нового SQL-файла AVG явно приведён к шести знакам для сравнения
со Spark. В блоке JOIN среднее округляется до двух знаков для чтения отчёта.

Справочник `memory.default.region_groups` хранится в памяти Trino. После его
перезапуска выполните блок `DROP TABLE IF EXISTS` / `CREATE TABLE` из блока 5 SQL-файла
перед JOIN. Этот блок пересоздаёт только учебный справочник. Порядок повторения примера: [этап 0 домашнего задания](homework_01.md#0-после-семинара-среда-и-учебный-пример).

## Альтернатива: CLI без DataGrip

DataGrip не обязателен и может требовать отдельной лицензии. После трёх Spark-шагов из `infra/` выполните:

```bash
docker compose exec -T trino trino < trino/scripts/seminar_demo.sql
```

Это тот же SQL. Скрипт пересоздаёт только учебный справочник `memory.default.region_groups`. Для своей сдачи используйте собственный `queries.sql`; SQL-клиент не влияет на оценку.

## Если подключение не получилось

| Симптом | Что проверить |
|---|---|
| Connection refused | Docker запущен, сервис `trino` работает (проверка: `docker compose ps`), порт `8088` |
| Не найден драйвер | Нажмите `Download missing driver files`; проверьте интернет |
| Ошибка SSL или пароля | Используется локальный HTTP, пароль пустой; не вводите пароль MinIO |
| Таблицы нет в дереве | Выбраны каталог `lakehouse` и схема `dwh`; обновлено дерево |
| SELECT 1 работает, events — нет | Статусы MinIO/PostgreSQL и наличие таблицы; сообщения `docker compose logs --tail=60 trino` |
| Не найден region_groups | Выполните блок создания справочника из SQL-файла |

Официальное описание адреса и параметров: [Trino JDBC](https://trino.io/docs/current/client/jdbc.html).
