# Схема таблицы lakehouse.naermishov.weather

Источник: Open-Meteo Historical Weather API (архив ERA5). Одна строка —
это один час наблюдений в одном городе. Таймзона везде UTC (запрошена явно
параметром `timezone=UTC`, скрипты Spark дополнительно фиксируют
`spark.sql.session.timeZone=UTC`).

| Поле | Тип Spark SQL | Nullable | Смысл и ограничения |
|---|---|---|---|
| `city` | STRING | нет | Название города, один из 8 фиксированных (см. report.md). Категориальное поле, используется для партиционирования Parquet. |
| `latitude` | DOUBLE | нет | Широта точки запроса к API, константа для города. |
| `longitude` | DOUBLE | нет | Долгота точки запроса к API, константа для города. |
| `event_ts` | TIMESTAMP | нет | Час наблюдения, UTC, без смещения в строке. |
| `event_date` | DATE | нет | Дата того же `event_ts`, отдельное поле для проверок и фильтров по датам. |
| `temperature_2m` | DECIMAL(5,2) | нет | Температура воздуха на высоте 2 м, °C. Отрицательные значения — норма (зима, северные города). Допустимый диапазон в проверках DQ: −55..45. |
| `relative_humidity_2m` | DECIMAL(5,2) | может быть NULL | Относительная влажность, %. Допустимый диапазон: 0..100. |
| `precipitation_mm` | DECIMAL(6,2) | может быть NULL | Сумма осадков за час, мм. Должно быть ≥ 0. |
| `wind_speed_10m` | DECIMAL(6,2) | может быть NULL | Скорость ветра на высоте 10 м, км/ч. Должно быть ≥ 0. |

Ключ уникальности строки — пара `(city, event_ts)`: для каждого города и
каждого часа периода источник отдаёт ровно одно наблюдение. Отдельного
суррогатного id не вводили, чтобы не плодить поле только "для количества".

## Что нельзя утверждать по этому набору

- Это данные реанализа (модельная интерполяция ERA5), а не показания
  конкретной метеостанции — значения по городу являются оценкой для точки
  с заданными координатами, а не измерением на конкретном посту.
- Осадки и ветер приведены для полноты набора; исследовательский вопрос
  ДЗ отвечает только на температуру, остальные поля не были нужны, но
  оставлены как дополнительные меры и для отдельного DQ-примера.
- Разбиение по федеральным округам в справочнике `memory.default.city_regions`
  — упрощение из 5 наименований для демонстрации LEFT JOIN, а не полный
  классификатор регионов РФ.
